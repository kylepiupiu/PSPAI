# PSPAI 首次原生 AI 问答里程碑

日期：**2026-10-14（北京时间凌晨）**

## 用户实机验证

在 PSP 3006 上运行 **PSPAI v0.3.1 原生 EBOOT.PBP**，PSP 通过 ESP32-S3 开放热点 `wifi4psp` 和 TCP 桥接连接 Mac Relay；Mac Relay 调用 ModelScope 千问；回答成功显示在 PSP 屏幕。用户确认：“成功了！”

首次测试的提问围绕 GPS 卫星定位与爱因斯坦相对论，目的是检查真实 AI 生成和多步解释。

## 缺陷记录

v0.3 第一次实机按 △ 后发生卡顿，尝试退出卡在“请稍等”。源码检查发现网络接收没有明确超时且 HOME 退出标记不能中断阻塞操作。v0.3.1 增加轮询、30 秒接收超时及分阶段日志，重新通过 PSPDEV GitHub Actions 构建，用户随后报告一次问答成功。

## 继续验证的范围

连续提问、长回答换页、HOME 退出、断网恢复、中文输入显示、其他 PSP 硬件与系统。Mac Relay 独立于 PSP 与 ESP32，是当前必需的中继。

正式记载：**这是 PSPAI 第一次在 PSP 3006 上完成原生 AI 问答，不等于完整产品验收或正式稳定版。**
