# 安全与隐私（公开测试项目）

- ESP32 的 PSP 热点 `wifi4psp` **没有密码**，故只能在可信实验网络使用；附近设备可连接并尝试访问服务。
- PSP→ESP32→Mac 的通信未加密；数据和网页管理员密钥可能被监听。**不适合公众环境、企业敏感资料或任何秘密信息。**
- Mac Relay 会向 ModelScope API 发送问题，不是本地离线 AI。
- ModelScope Token 仅在本机交互输入（`start_relay.py`）；**不能写进代码、提交 git、分享截图或测试日志**。
- `config.h` 模板内仅使用空白 Wi-Fi 密码；个人实际配置不要上传。ESP32 设备管理员密钥在真实设备上随机生成，不要公开。
- Mac Relay 的 IP 白名单与限制措施是基础保护，**不是强认证**；请另外用可信的网络隔离保障安全。
- 使用和转载应遵守 PSPSDK、硬件厂商、模型平台及相关服务的许可证与服务条款。
- 当前仅验证 PSP 3006 一次真实问答，安全性、健壮性、兼容性未经过正式审计。

- 设备配置请复制 `esp32/.../config.example.h` 为私有的 `config.h`；该文件已列入 `.gitignore`。修改模板前检查不要出现私人账号密码。
